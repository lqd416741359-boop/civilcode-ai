# Judicial interpretations — verification checklist

This file is a routing/checklist, not a substitute for the current official text.

## Always consider whether an SPC interpretation materially changes application
Common high-value categories include:
- temporal application of the Civil Code;
- General Provisions;
- contracts;
- guarantee/security system;
- marriage and family;
- inheritance;
- property, tort or subject-specific civil interpretations where relevant;
- evidence, jurisdiction, preservation, enforcement and civil procedure.

## Verification workflow
1. Search the Supreme People's Court official site / official gazette for the subject.
2. Confirm the exact title and current effective/amended status.
3. Open the full official text.
4. Verify the exact provision relied on.
5. State that the authority is a judicial interpretation, not a Civil Code article.
6. If an older interpretation conflicts with a later rule or has been repealed/amended, do not use the stale text.

## Case guidance
Official guiding/typical/reference/gazette cases may be useful for reasoning and factual analogy. Summarize the relevant holding/application without overclaiming precedential force. Note meaningful factual differences.
